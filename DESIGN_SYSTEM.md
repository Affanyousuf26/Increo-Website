# INCREO design system

## Foundation

- Primary purple: `#6f41c6`
- Soft black: `#0f0f0f`
- Soft white: `#fafafa`
- Raised surface: `#191919`
- Border: `#343434`
- Muted text: `#b5b5b5`
- Accent purple: `#a887f1`

Space Grotesk Variable is self-hosted through the project dependency. Display headings use a compact uppercase treatment with fluid `clamp()` sizing. Hanson Bold may replace display typography only after licensing is approved.

Layout uses a maximum 86rem shell, generous vertical rhythm, thin technical grids, square controls, and restrained purple accents. Motion is brief and progressive; all content remains visible without JavaScript and animation is disabled for reduced-motion preferences.

Responsive breakpoints are content-led at 900px and 640px. Interactive targets should be at least 44px on touch screens.
